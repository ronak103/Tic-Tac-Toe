# Tic-Tac-Toe

A simple **console-based Tic Tac Toe game** built using **Python**.  
This project is beginner-friendly and demonstrates basic concepts like loops, functions, condition checking, and user input handling.

---

## 📌 Features

- 3×3 Tic Tac Toe board
- Two-player mode (Player X vs Player O)
- Console-based user interaction
- Input validation (no overwriting moves)
- Automatic win and draw detection
- Clean and readable code

---

## 🛠️ Technologies Used

- **Python 3**
- No external libraries required
